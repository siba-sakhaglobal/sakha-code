# Phase 07: UI and Daemon

## Goal

Build user-facing supervision surfaces.

## Tasks

### 07.1 Daemon API

- Event stream.
- Permission decision endpoint.
- Loop endpoints.
- Audit endpoints.
- Compression stats endpoint.

### 07.2 CLI

- Chat mode.
- Run mode.
- Goal commands.
- Loop commands.
- Config commands.
- Doctor command.

### 07.3 TUI

- Chat stream.
- Tool timeline.
- Permission prompts.
- Diff viewer.
- Loop dashboard.

### 07.4 Web UI

- Sessions list.
- Session timeline.
- Tool/audit view.
- Research evidence view.
- Compression stats.
- Settings.

### 07.5 Tauri Desktop

- Start/attach local daemon.
- Render web UI.
- Native notifications.
- Open workspace picker.

## Definition of Done

- User can run a session from CLI.
- User can approve tools in TUI/web.
- User can inspect loop progress.
- User can view compressed vs raw artifacts.
- Desktop app starts daemon and connects.
